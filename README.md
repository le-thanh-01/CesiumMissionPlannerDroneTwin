# DroneTwin — DJI Neo 2 Digital Twin

Unreal Engine 4.27 + Cesium + ArduPilot SITL + Mission Planner.
Lái drone từ Unreal bằng bàn phím, ArduPilot tính vật lý bay,
Cesium dựng địa hình thật.

Hướng dẫn cài đặt và chạy đầy đủ: [CHECKPOINT.md](CHECKPOINT.md)

Lưu ý: `SYSID_MYGCS` phải bằng 255, xem mục 2.4.
